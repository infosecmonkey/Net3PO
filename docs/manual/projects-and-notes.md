# Projects and notes

A **project** collects results and notes for one job, so you can hand over a single report at
the end. Projects live on this computer only.

## Projects

Open **Workspace > Projects** to create, rename, review and export projects. Details of the
panel are on the [Projects](tools/projects.md) page.

Add a result to a project from any tool that has an **Export** menu:

1. Run the tool.
2. Open **Export**. Under **Add to project**, pick one of your recent projects, or choose
   **New project...**, type a name and press Enter.
3. The current result is saved into the project as a snapshot. Running the tool again later
   does not change what was saved.

## Notes

The Notes pop-out docks on the right of every tool.

- **Open or hide:** **Cmd+Shift+N** (macOS), **Ctrl+Shift+N** (Windows, Linux), or the close
  button. **Esc** also hides it. Hiding keeps your draft.
- **Pick a project** at the top, or create one with **New project...**.
- **Write.** A new note is tied to the active project and the tool you are in when you start
  typing. It keeps that link if you switch tools before saving.
- **Drafts are kept** on every keystroke, so closing the panel or the app does not lose text.
  The draft becomes part of the project only when you click **Save**.
- **New note** starts another note; **Edit** and **Delete** act on saved notes. Delete asks for
  confirmation.
- **This tool / All** switches the list between notes for the current tool and every note in
  the project.
- The panel can be resized by dragging its left edge.

Notes are included in the project export, grouped by tool.

## Where it is stored

Projects and notes are files in the app data folder (see [Privacy and data](privacy.md)). The
unsaved draft is kept in the app's local web storage. Nothing is synced or uploaded.
