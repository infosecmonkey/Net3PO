# Security policy

Net3PO handles hostile network input and stores SSH secrets in the OS
keychain, so security reports are welcome.

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/infosecmonkey/Net3PO/security/advisories/new)
rather than in a public issue. Include the version, OS, steps to reproduce and
the impact you see. You should get a reply within a few days.

Only the latest release is supported with fixes.
