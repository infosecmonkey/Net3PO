## Built-in command descriptions for the shell explainer. Written for Net3PO.
## Format is described in db.rs. Lines starting with ## are comments.

## ---------- Shells and interpreters ----------

@cmd bash sh dash zsh ksh
Run a shell: execute commands from a string (-c), a script file, or standard input.
-c | Read commands from the first operand (the command string) instead of a file.
-i | Run as an interactive shell.
-l --login | Act as a login shell (read profile files).
-s | Read commands from standard input; remaining operands become positional parameters.
-x | Trace: print each command before running it (xtrace).
-e | Exit as soon as a command fails (errexit).
-u | Treat use of an unset variable as an error (nounset).
-v | Print input lines as they are read (verbose).
-n | Read commands but do not run them (syntax check).
-o <option> | Set a shell option by name, for example pipefail.
-p | Privileged mode: do not read the environment's startup files; keep the effective user ID.
-r | Restricted shell.
--norc | Do not read the interactive startup file (~/.bashrc).
--noprofile | Do not read login profile files.
--posix | Follow the POSIX standard where Bash differs.
@shellc
@arg script | Script file to run; further operands become $1, $2 and so on.

@cmd python python3 python2
Run the Python interpreter.
-c <program> | Run the Python code given as a string.
-m <module> | Run a library module as a script, for example http.server.
-u | Unbuffered standard output and error.
-i | Drop into the interactive prompt after running the script.
-E | Ignore PYTHON* environment variables.
-I | Isolated mode: ignore environment variables and the user site directory.
-B | Do not write .pyc bytecode files.
-O | Remove assert statements and __debug__ code.
-q | Do not print the version banner in interactive mode.
-V --version | Print the Python version.
-W <arg> | Control warnings.
-X <option> | Set an implementation-specific option.
@arg script | Script file to run; further operands become sys.argv.

@cmd perl
Run the Perl interpreter.
-e <program> | Run one line of Perl code given as a string.
-E <program> | Like -e, with all optional features enabled.
-n | Loop over input lines without printing them.
-p | Loop over input lines and print each one (like sed).
-i [ext] | Edit files in place, keeping a backup with the given extension.
-l | Handle line endings automatically.
-a | Autosplit each input line into @F (with -n or -p).
-M <module> | Load a module before running the program.
-w | Turn on warnings.
-0 [octal] | Set the input record separator.
@arg script | Script file to run.

@cmd ruby
Run the Ruby interpreter.
-e <program> | Run one line of Ruby code given as a string.
-n | Loop over input lines.
-p | Loop over input lines and print each one.
-r <library> | Require a library before running.
-w | Turn on warnings.
@arg script | Script file to run.

@cmd php
Run the PHP command-line interpreter.
-r <code> | Run PHP code given as a string, without <?php tags.
-f <file> | Parse and run a file.
-S <addr:port> | Start the built-in web server.
-t <docroot> | Document root for the built-in web server.
-n | Do not load php.ini.
-d <key=value> | Set an ini setting.
@arg file | Script file to run.

@cmd node nodejs
Run JavaScript with Node.js.
-e --eval <script> | Run JavaScript given as a string.
-p --print <script> | Run JavaScript given as a string and print the result.
-r --require <module> | Preload a module.
-i --interactive | Open the REPL even if standard input is not a terminal.
@arg script | Script file to run.

@cmd pwsh powershell powershell.exe
Run PowerShell.
-c -Command <command> | Run the given PowerShell command text.
-e -EncodedCommand <base64> | Run a Base64-encoded (UTF-16LE) command. Common in obfuscated scripts.
-ec <base64> | Short form of -EncodedCommand.
-enc <base64> | Short form of -EncodedCommand.
-nop -NoProfile | Do not load the PowerShell profile.
-noni -NonInteractive | Do not present an interactive prompt.
-w -WindowStyle <style> | Window style, for example Hidden to run without a visible window.
-ep -ExecutionPolicy <policy> | Execution policy for this session, for example Bypass.
-f -File <file> | Run a script file.
-sta | Start in single-threaded apartment mode.
-NoLogo | Hide the startup banner.

@cmd osascript
Run AppleScript or JavaScript for Automation (macOS).
-e <statement> | Run one line of script given as a string; may repeat.
-l <language> | Script language, for example JavaScript.
@arg script | Script file to run.

@cmd awk gawk mawk nawk
Pattern scanning and text processing language.
-F <fs> | Field separator (default whitespace).
-v <var=value> | Set a variable before the program starts.
-f <progfile> | Read the awk program from a file.
@arg program | The awk program, for example '{print $1}': runs the action for each input line.
@arg file | Input file to process.

@cmd sed gsed
Stream editor: apply edit commands to each input line.
-n --quiet | Do not print lines automatically; print only with the p command.
-e --expression <script> | Add an edit script.
-f --file <file> | Read edit commands from a file.
-i --in-place [suffix] | Edit files in place (optional backup suffix).
-E -r --regexp-extended | Use extended regular expressions.
-s --separate | Treat files as separate streams.
-z --null-data | Lines are separated by NUL characters.
@arg script | Edit script, for example s/old/new/g (substitute every match on each line).
@arg file | Input file.

## ---------- Wrappers that run another command ----------

@cmd sudo
Run a command as another user, by default root.
-u --user <user> | Run as this user instead of root.
-g --group <group> | Run with this primary group.
-E --preserve-env | Keep the caller's environment variables.
-H --set-home | Set HOME to the target user's home directory.
-i --login | Run the target user's login shell.
-s --shell | Run a shell (or the command through a shell).
-b --background | Run the command in the background.
-k --reset-timestamp | Ignore cached credentials; ask for the password again.
-n --non-interactive | Never prompt for a password; fail instead.
-S --stdin | Read the password from standard input.
-l --list | List the commands the user may run.
-v --validate | Refresh cached credentials without running a command.
-A --askpass | Use a helper program to ask for the password.
@wrap 0
@arg command | Command to run with elevated rights.

@cmd doas
Run a command as another user, by default root (OpenBSD style).
-u <user> | Run as this user.
-s | Run a shell.
-n | Never prompt for a password.
@wrap 0

@cmd su
Switch to another user, by default root.
-c --command <command!> | Run this command as the target user instead of opening a shell.
-l --login | Start a login shell with the target user's environment.
-s --shell <shell> | Use this shell.
-m -p --preserve-environment | Keep the current environment.
@arg user | User to switch to (default root).

@cmd env
Run a command with a modified environment, or print the environment.
-i --ignore-environment | Start with an empty environment.
-u --unset <name> | Remove a variable from the environment.
-C --chdir <dir> | Change to this directory first.
-S --split-string <string> | Split the string into separate arguments (used in #! lines).
-0 --null | End each output line with NUL.
@wrap 0
@arg command | Command to run with the environment above.

@cmd nohup
Run a command that keeps running after you log out (ignores the hangup signal). Output goes to nohup.out unless redirected.
@wrap 0

@cmd nice
Run a command with a changed scheduling priority.
-n --adjustment <n> | Add n to the niceness (higher is lower priority).
@wrap 0

@cmd ionice
Run a command with a changed I/O scheduling class.
-c --class <class> | Scheduling class: 1 realtime, 2 best-effort, 3 idle.
-n --classdata <level> | Priority within the class.
-p --pid <pid> | Change an existing process instead.
@wrap 0

@cmd time
Run a command and report how long it took.
-p | Use the portable POSIX output format.
-v --verbose | Detailed resource usage (GNU time).
@wrap 0

@cmd timeout gtimeout
Run a command with a time limit and kill it if it runs too long.
-s --signal <signal> | Signal to send on timeout (default TERM).
-k --kill-after <duration> | Send KILL if still running this long after the first signal.
--preserve-status | Exit with the command's status even on timeout.
--foreground | Allow the command to read from the terminal.
@wrap 1
@arg duration | Time limit, for example 10s, 5m or 1h.

@cmd exec
Replace the shell with the given command (no new process). With only redirections, changes the shell's own file descriptors.
-a <name> | Pass this as the command's name (argv[0]).
-c | Run the command with an empty environment.
-l | Put a dash in front of argv[0], like a login shell.
@wrap 0

@cmd command
Run a command, skipping shell functions and aliases with the same name.
-v | Print how the name would be resolved instead of running it.
-V | Describe how the name would be resolved.
-p | Use a default PATH that finds the standard utilities.
@wrap 0

@cmd builtin
Run a shell builtin, skipping functions with the same name.
@wrap 0

@cmd xargs
Build and run command lines from standard input: input items become arguments of the command.
-0 --null | Input items are separated by NUL (pairs with find -print0).
-I <replace> | Replace this string in the command with each input item; runs once per item.
-n --max-args <n> | Use at most n arguments per command line.
-P --max-procs <n> | Run up to n commands in parallel.
-d --delimiter <char> | Input items are separated by this character.
-r --no-run-if-empty | Do not run the command if there is no input.
-t --verbose | Print each command before running it.
-p --interactive | Ask before running each command.
-L --max-lines <n> | Use at most n input lines per command line.
-a --arg-file <file> | Read items from a file instead of standard input.
@wrap 0
@arg command | Command to run (default echo).

@cmd watch
Run a command repeatedly and show its output full screen.
-n --interval <seconds> | Seconds between runs (default 2).
-d --differences | Highlight changes between runs.
-t --no-title | Hide the header.
-g --chgexit | Exit when the output changes.
@wrap 0

@cmd strace
Trace the system calls a command makes.
-f | Follow child processes.
-p <pid> | Attach to a running process.
-e <expr> | Choose which calls to trace, for example trace=network.
-o <file> | Write the trace to a file.
-s <size> | Longest string to print.
@wrap 0

@cmd stdbuf
Run a command with changed buffering of its standard streams.
-i --input <mode> | Buffering of standard input.
-o --output <mode> | Buffering of standard output (0 or L for unbuffered or line buffered).
-e --error <mode> | Buffering of standard error.
@wrap 0

@cmd setsid
Run a command in a new session, detached from the terminal.
-f --fork | Always fork.
-w --wait | Wait for the command and return its exit status.
@wrap 0

@cmd chroot
Run a command with a different root directory.
--userspec <user:group> | Run as this user and group.
@wrap 1
@arg newroot | Directory to use as /.

@cmd flock
Run a command while holding a file lock.
-n --nonblock | Fail instead of waiting if the lock is held.
-x --exclusive | Take an exclusive lock (default).
-s --shared | Take a shared lock.
-w --timeout <seconds> | Give up after this long.
-c --command <command!> | Run this command string through the shell.
@wrap 1
@arg lockfile | File to lock.

@cmd caffeinate
Keep a Mac awake while a command runs (macOS).
-d | Prevent the display from sleeping.
-i | Prevent idle sleep.
-s | Prevent sleep on AC power.
-t <seconds> | Stay awake for this long.
@wrap 0

@cmd eval
Join the arguments into one string and run it as shell commands. The text is only known at run time.
@remote 0

@cmd ssh
Log in to a remote host or run a command there over SSH.
-p <port> | Remote port (default 22).
-l <user> | Remote user name.
-i <identity_file> | Private key file to authenticate with.
-L <local_forward> | Forward a local port to a remote address: [bind:]port:host:hostport.
-R <remote_forward> | Forward a remote port back to a local address (reverse tunnel).
-D <port> | Dynamic SOCKS proxy on this local port.
-J <jump_host> | Connect through this jump host.
-N | Do not run a remote command (tunnels only).
-f | Go to the background after authentication.
-T | Do not allocate a terminal.
-t | Force a terminal, for interactive programs.
-v | Verbose debug output; repeat for more.
-q | Quiet mode.
-C | Compress traffic.
-A | Forward the authentication agent.
-X | Forward X11.
-o <option> | Set a config option, for example StrictHostKeyChecking=no.
-F <configfile> | Use this config file.
-4 | IPv4 only.
-6 | IPv6 only.
@remote 1
@arg destination | Host to connect to, as [user@]host.

## ---------- Network ----------

@cmd curl
Transfer data from or to a server (HTTP, HTTPS, FTP and more).
-o --output <file> | Write output to this file instead of standard output.
-O --remote-name | Save to a local file named like the remote file.
-s --silent | Silent mode: no progress meter or error messages.
-S --show-error | Show errors even with -s.
-L --location | Follow redirects.
-k --insecure | Do not verify the server's TLS certificate.
-f --fail | Fail silently (no output) on HTTP errors.
-I --head | Fetch headers only (HEAD request).
-i --include | Include response headers in the output.
-v --verbose | Show the request, response headers and TLS details.
-X --request <method> | HTTP method to use, for example POST.
-H --header <header> | Add a request header.
-d --data <data> | Send data in a POST request body.
--data-binary <data> | Send data exactly as given, with no processing.
--data-urlencode <data> | URL-encode and send data in a POST body.
-F --form <name=content> | Send multipart form data (file upload with @file).
-T --upload-file <file> | Upload this file.
-u --user <user:password> | Server user name and password.
-A --user-agent <name> | User-Agent header to send.
-e --referer <url> | Referer header to send.
-b --cookie <data> | Send cookies (string or file).
-c --cookie-jar <file> | Write received cookies to this file.
-x --proxy <proxy> | Use this proxy.
-m --max-time <seconds> | Maximum time for the whole transfer.
--connect-timeout <seconds> | Maximum time to connect.
-r --range <range> | Fetch only a byte range.
-C --continue-at <offset> | Resume a transfer.
-w --write-out <format> | Print information after the transfer, for example %{http_code}.
-G --get | Send -d data as a query string with GET.
--compressed | Ask for a compressed response and decompress it.
--resolve <host:port:addr> | Use this address for host and port instead of DNS.
-4 --ipv4 | IPv4 only.
-6 --ipv6 | IPv6 only.
--retry <num> | Retry this many times on transient errors.
--cacert <file> | CA certificate bundle to verify the server with.
--cert <certificate> | Client certificate.
--key <key> | Client private key.
--http2 | Use HTTP/2.
--tlsv1.2 | Use TLS 1.2 or later.
-Z --parallel | Run transfers in parallel.
@arg URL | URL to fetch.

@cmd wget
Download files over HTTP, HTTPS or FTP.
-O --output-document <file> | Write the download to this file ("-" for standard output).
-q --quiet | No output.
-c --continue | Resume a partly downloaded file.
-r --recursive | Download recursively.
-l --level <depth> | Recursion depth.
-np --no-parent | Do not ascend to the parent directory when recursive.
-m --mirror | Mirror a site (recursive, timestamps, infinite depth).
-P --directory-prefix <dir> | Save files under this directory.
-b --background | Go to the background immediately.
-U --user-agent <agent> | User-Agent header to send.
--no-check-certificate | Do not verify the server's TLS certificate.
-T --timeout <seconds> | Network timeout.
-t --tries <n> | Number of retries.
-i --input-file <file> | Read URLs from a file.
--header <header> | Add a request header.
--post-data <data> | Send a POST request with this body.
-S --server-response | Print the server's response headers.
@arg URL | URL to download.

@cmd nc ncat netcat
Netcat: read and write raw TCP or UDP connections.
-l | Listen for an incoming connection instead of connecting.
-p <port> | Local port (with -l on some versions).
-u | Use UDP instead of TCP.
-v | Verbose.
-n | Do not resolve names; numeric addresses only.
-z | Scan for listening ports without sending data.
-w <seconds> | Timeout for connects and idle connections.
-k | Keep listening after a client disconnects.
-e <program> | Run this program with its input and output connected to the socket. Gives a remote shell when the program is a shell.
-c <command!> | Run this command through the shell connected to the socket (remote shell).
-N | Close the connection after end of input.
-q <seconds> | Quit this long after end of input.
-s <source> | Local source address.
-4 | IPv4 only.
-6 | IPv6 only.
@arg host | Host to connect to.
@arg port | Port or port range.

@cmd socat
Relay data between two addresses (sockets, files, programs, terminals).
-d | Print diagnostics; repeat for more.
-v | Log transferred data to standard error.
-u | One direction only, from the first address to the second.
-T <timeout> | Inactivity timeout.
@arg address | Address, for example TCP:host:port, TCP-LISTEN:port, EXEC:cmd or STDIO. EXEC or SYSTEM with a shell gives a remote shell.

@cmd telnet
Connect to a TCP port interactively (unencrypted).
-l <user> | User name for the remote login.
@arg host | Host to connect to.
@arg port | Port (default 23).

@cmd ping ping6
Send ICMP echo requests to test reachability and round-trip time.
-c <count> | Stop after this many packets.
-i <interval> | Seconds between packets.
-s <size> | Payload size in bytes.
-t <ttl> | Time to live (Linux), or timeout in seconds (macOS).
-W <timeout> | Time to wait for each reply.
-n | Numeric output only.
-q | Quiet: print only the summary.
-f | Flood ping (root only).
-D | Do not fragment (macOS); print timestamps (Linux).
-M <hint> | Path MTU discovery: do sets don't-fragment (Linux).
-I <interface> | Send from this interface or address.
-4 | IPv4 only.
-6 | IPv6 only.
@arg host | Host to ping.

@cmd traceroute traceroute6 tracepath
Show the routers on the path to a host.
-n | Numeric addresses; no DNS lookups.
-m <max_ttl> | Maximum number of hops.
-q <nqueries> | Probes per hop.
-w <waittime> | Seconds to wait for each reply.
-I | Use ICMP echo probes.
-T | Use TCP SYN probes.
-p <port> | Destination port.
-4 | IPv4 only.
-6 | IPv6 only.
@arg host | Destination host.

@cmd nmap
Network scanner: discover hosts, open ports and services.
-sS | TCP SYN scan (needs root).
-sT | TCP connect scan.
-sU | UDP scan.
-sV | Detect service versions.
-sn | Host discovery only, no port scan.

-Pn | Skip host discovery; treat all hosts as up.
-O | Detect the operating system.
-A | Aggressive: OS and version detection, scripts and traceroute.
-p <ports> | Ports to scan, for example 22,80,443 or 1-65535.
-F | Fast: scan fewer ports.
-T0 | Timing template 0 (paranoid, slowest).
-T4 | Timing template 4 (aggressive, faster).
-T5 | Timing template 5 (insane, fastest).
-oN <file> | Normal output to a file.
-oX <file> | XML output to a file.
-oG <file> | Greppable output to a file.
-oA <basename> | Output in all formats.
-v | Verbose.
-n | No DNS resolution.
-iL <file> | Read targets from a file.
--script <scripts> | Run these NSE scripts.
--open | Show only open ports.
--top-ports <n> | Scan the n most common ports.
@arg target | Host, address range or network to scan.
